# Website QA & Business Analysis - Contact Page Audit

**Role:** QA Engineer & Business Analyst | **Project Type:** Personal Portfolio (Case Study)

This is my personal portfolio project where I took **EpicMinds website as a sample** to perform end-to-end QA & BA.

### 🎯 Objective
Improve Contact Us page to increase lead conversion by 30% and fix UX issues across devices.

### 🔍 What I Did
- Audited 20 website pages for content & SEO
- Wrote 15 Manual Test Cases (73% Pass Rate)
- Logged 4 Bugs with Severity & Priority
- Created BRD for Contact Page Revamp (11 Sections)
- Built Excel Dashboard with KPIs

### 🐛 Key Bugs Found
- No email validation in contact form
- No success message after submission
- Mobile responsiveness break (320px-768px)
- Social links open in same tab

### ✅ Proposed Solution in BRD
- Email regex validation + error toast
- Success message: "Thank you for contacting us"
- Mobile responsive fix
- External links in new tab
- CAPTCHA + WhatsApp integration

### 📂 Deliverables
- `/BRD.pdf` - Business Requirement Document
- `Task Tracker`, `Content Audit`, `Test Cases`, `Bug Report`, `Dashboard`

Manual Testing, Business Analysis, BRD Writing, Test Case Design, Bug Reporting, Excel Dashboard, SDLC
